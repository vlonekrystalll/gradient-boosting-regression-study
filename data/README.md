# Данные начального эксперимента

Источник: [UCI Concrete Compressive Strength](https://archive.ics.uci.edu/dataset/165/concrete+compressive+strength).
Автор: I-Cheng Yeh. Цитирование: Yeh, I. (1998), DOI [10.24432/C5PK67](https://doi.org/10.24432/C5PK67). Лицензия: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

`concrete.csv` получен из `Concrete_Data.xls` официального архива UCI. Изменены формат файла и названия колонок. Все 1 030 строк и их порядок сохранены. Дубликаты удаляются при выполнении ноутбука, не в этом CSV. Соответствие исходных названий и SHA-256 записаны в `source.json`.

| Колонка | Значение | Единица |
| --- | --- | --- |
| cement | Цемент | кг/м³ |
| slag | Доменный шлак | кг/м³ |
| fly_ash | Зола-унос | кг/м³ |
| water | Вода | кг/м³ |
| superplasticizer | Суперпластификатор | кг/м³ |
| coarse_aggregate | Крупный заполнитель | кг/м³ |
| fine_aggregate | Мелкий заполнитель | кг/м³ |
| age_days | Возраст образца | дни |
| strength_mpa | Прочность на сжатие, целевая величина | МПа |

`row_id` в файлах результатов — позиция строки в исходном CSV, начиная с нуля. После удаления полных дубликатов номера не переназначаются.

`UCI_Readme.txt` — описание из исходного архива без изменений.
