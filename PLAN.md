# План следующих этапов

Это черновой план. Описанные ниже эксперименты ещё не запускались, их результатов в репозитории нет.

## 1. Первое сравнение бустингов

Обучить XGBoost, LightGBM и CatBoost на том же составе признаков и разбиении. Сравнить с текущей линейной моделью по RMSE, дополнительно сохранить MAE и R². Масштабирование для деревьев не требуется.

## 2. Число деревьев и глубина

Начальная сетка для обсуждения:

| Параметр | Значения |
| --- | --- |
| Число деревьев | 50, 100, 200, 500 |
| Максимальная глубина | 2, 4, 6, 8 |
| Learning rate | 0,05, фиксирован |

Для каждой пары сохранить ошибку train и validation, время обучения и остальные параметры. В первой серии не использовать early stopping: важно проверить заявленное число деревьев, а не скрыто остановиться раньше. Отдельно можно исследовать early stopping после основных кривых.

Для LightGBM явно задать `num_leaves` согласованно с глубиной, чтобы скрытое ограничение числа листьев не меняло смысл опыта. Остальные настройки тоже сохранять. Одинаковая глубина в разных библиотеках не даёт одинаковые деревья, поэтому сначала интерпретировать кривые внутри каждой модели, затем сопоставлять результаты.

## 3. Проверка переобучения

Построить ошибки в зависимости от числа деревьев при нескольких глубинах. Искать режимы, в которых ошибка train продолжает уменьшаться, а ошибка validation начинает расти. Не называть переобучением любой ненулевой разрыв между ними.

После первого опыта проверить устойчивость наблюдений на нескольких групповых разбиениях обучающей части. Не выбирать лучший seed и не переносить удачные строки из теста в обучение.

## 4. Финальная проверка

Зафиксировать методику и выбранные параметры по обучению и валидации. При необходимости переобучить выбранную модель на train + validation, затем один раз оценить на test. Отдельно описать ограничения небольшого датасета и приблизительной группировки рецептур.
